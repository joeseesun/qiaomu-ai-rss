# 公众号原文入口修复（2026-10-21）

## 原因与证据

公开接口 `/api/entry/c36933319d51c7b6381bb321b519fb56` 正文末尾包含 `wechat2rss.bestblogs.dev/link-proxy/` 的“跳转微信打开”。curl 实测中转先 301 去尾斜杠，再 302 到 `weixin://dl/business/`；不能作为普通 HTTPS 页面加载。新智元文章的本地正文缓存也包含同类链接。直接访问公众号 HTTPS 原文时，本次网络收到“环境异常，完成验证后即可继续访问”，这是另一层微信访问验证，不代表正文服务无内容。

## 修复范围

在正文清洗后仅解析已知 BestBlogs link-proxy 的 `u` 目标，要求目标为 `https://mp.weixin.qq.com/s` 或短链接路径且不含凭据，保留原文参数。展示与导出共用此路径，因此历史缓存生效且无需改写持久数据。原“跳转微信打开/跳转到微信打开”文案复用既有八语言原文入口词条；其他标签保持原样。没有操作微信客户端或微信内嵌页面。
