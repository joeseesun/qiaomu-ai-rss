# 公众号订阅调研（2026-09-07）

RSSHub 是网站转 RSS 的服务，并不是阅读频道。原来的两个条目是示例路由，而非 RSSHub 的能力上限。本版探索入口改为“网站与公众号”，保留少量网站动态示例，并提供公众号公共目录和自建服务入口；不把未经检查的路由填入精选。

## 可以直接使用

[Wechat2RSS 公共目录](https://wechat2rss.xlab.app/list/all) 提供部分公众号 RSS。用户复制具体 RSS 地址，在“我的订阅”添加即可。公共目录有覆盖范围，不代表任意公众号都已收录；服务更新不是即时推送。

## 更多公众号

- [WeRSS](https://github.com/rachelos/we-mp-rss)：自行部署采集服务，支持公众号管理、定时更新和 RSS 输出。采集模式涉及扫码授权或 Cookie，需维护授权状态。插件消费生成的 RSS，不保存微信登录凭据。
- [Wechat2RSS 私有部署](https://wechat2rss.xlab.app/deploy/)：供应商声明支持任意公众号和全文输出，但软件授权收费、需自行部署。当前条款限个人学习研究，禁止商用和内容分发，不能直接作为我们的共享公共后端。

建议先保持标准 RSS 地址接入；下一阶段可添加用户自有服务的连接器（实例地址、授权状态、搜索公众号、添加订阅）。本次没有部署服务、代用户扫码或购买授权，也未承诺任意公众号均可稳定抓取。需要选定服务并验证采集/授权生命周期后，才适合提供内置账号搜索。
