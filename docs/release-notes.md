## 中文

- 新增「从本地删除」：在文章列表右键或阅读器更多菜单中移除不感兴趣的文章，刷新、重启后仍保持隐藏，不请求服务器删除。
- 删除后可立即撤销，也可在设置 → 订阅 → 已删除文章中搜索、逐篇恢复或恢复全部。收藏、稍后读关系、阅读记录和已保存笔记保留。
- 支持个人订阅、精选与播客；库内 Markdown 文件不提供此操作。移动布局已检查，实体手机与 Windows 闪烁反馈尚未完成实机验证。

- 更新 HTML 净化依赖，修复上游安全公告涉及的依赖版本。

## English

- Add Delete locally to article context menus and reader actions. Hidden articles stay hidden after refresh or restart; no server deletion is requested.
- Undo immediately or search and restore deleted articles under Settings → Sources → Deleted articles. Favorites, read-later relationships, reading history and saved notes are preserved.
- Support personal feeds, curated articles and podcasts; vault Markdown files are excluded. Narrow layouts were checked; physical phones and the reported Windows flickering remain unverified.
- Update the HTML sanitization dependency to its patched upstream release.
