Read RSS articles aloud without another plugin. The reader toolbar supports pause/resume, previous/next sentence, speed, searchable voices and paragraph following. Original, rewritten and translated articles keep independent reading positions; selections never overwrite full-article progress.

Speech settings include provider/model choices, key application links, model-scoped voices, account catalog refresh and local model readiness. Mac system speech automatically finds installed enhanced voices. Auditioning voices retains your reading sentence and restores it paused.

When Qiaomu Audio is also installed, starting or previewing speech pauses the other plugin. Settings can be copied once explicitly; local model data is shared, and either plugin continues working independently.

The engine is bundled from an immutable source revision. Validation includes automated tests and real macOS Obsidian checks for model/voice linkage, enhanced voice playback, progress and independent operation. Mobile and Windows device playback are not part of this host validation.
