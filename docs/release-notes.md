## 中文

- 自定义过「筛选乔木精选」的用户，以后乔木新增的来源也会自动勾上，不用再手动打开筛选去找。
- 只有新出现的来源会被加入，你之前看过并取消勾选的来源不会被加回来。
- 从 0.32.2 或更早版本升级的用户，这次会自动加入 8 个中文播客精读：张小珺商业访谈录、42章经、晚点聊、十字路口、AI炼金术、三五环、知行小酒馆、面基。
- 已通过单元测试与类型检查；实体手机与 Windows 未实机验证。

## English

- If you customized Qiaomu picks, sources added to Qiaomu later are now ticked for you automatically, so you no longer have to find them in the picker.
- Only sources that are new to you are added; anything you have already seen and unticked stays off.
- Upgrading from 0.32.2 or earlier adds the eight Chinese podcast close readings (Zhang Xiaojun, 42zhangjing, LateTalk, Crossing, AI Alchemy, 35huan, Zhixing Tavern, Mianji) to your selection.
- Covered by unit tests and type checking; physical phones and Windows remain untested.
